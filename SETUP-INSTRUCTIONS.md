# INSTRUCTIONS FOR FIRST-TIME SETUP

1. npm run setup in terminal
2. change 'description' field in package.json appropriately
3. check that name, repo url, bugs url and homepage url have been updated correctly
4. check that there is no "setup" entry in scripts
5. update git https url in README.md 'getting started' section (use the _ HTTPS _ url from the green code button)
6. update title in src > index.html
7. npm run dev to open webpack dev server
8. npm run cleanup to check for lint and prettier errors
9. npm run deploy to publish project when done
10. check that github pages is set to gh-pages branch in repo settings
11. when you're ready, delete this file!
