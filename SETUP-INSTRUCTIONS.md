# INSTRUCTIONS FOR FIRST-TIME SETUP

1. change 'name' field in package.json appropriately
2. change repo + bugs + homepage url appropriately (just change TEMPLATE_REPO to repo name)
3. change 'description' field in package.json appropriately
4. update git https url in README.md 'getting started' section (use the HTTPS url from the green code button)
5. update title in src > index.html
6. npm run dev to open webpack dev server
7. npm run cleanup to check for lint and prettier errors
8. npm run deploy to publish project when done
9. check that github pages is set to gh-pages branch in repo settings
10. when you're ready, delete this file!
